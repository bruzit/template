# Security Policy

Found a vulnerability? Please report it privately: [report a vulnerability](../../security/advisories/new). Don't open a public issue or pull request; that shows the problem to everyone before a fix exists.

## Reporting a Vulnerability

1. Go to this repository's **Security** tab and choose **Report a vulnerability** (GitHub private vulnerability reporting). Only you and I see the report.
2. Tell me what you found, how to reproduce it, and what an attacker could do with it.
3. I confirm I've got it and we work on the fix together in a private draft advisory.
4. I publish the fix and the advisory together. You're credited, unless you'd rather not be.

## Supported Versions

Fixes go to the latest release only (`v0` today). Older releases get no patches, so please upgrade.

## Response Times

BruzIT is a one-person project. I answer as soon as I can, best effort, with no SLA. If the issue is serious, say so in the report and I'll put it first.
